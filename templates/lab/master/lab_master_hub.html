Central Laboratory Architecture Principles

Single source of truth for all clinical diagnostic modules

Lab Master serves as the central, normalized repository for laboratory investigations, parameters, reference ranges, and diagnostic rules across VMMC ERP:

  • No Hardcoding: ATC automated generation, doctor window lookups, work orders, and result evaluation resolve parameters and ranges dynamically.
  • String Code Preservation: All codes (e.g. 00022681) retain exact leading zeros and format.
  • Eligibility Engine: Diagnoses and test suggestions strictly enforce patient gender, age limits, and pregnancy status.
